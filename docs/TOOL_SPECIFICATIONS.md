# Navbar Gallery FastMCP Tool Specifications

## Available Tools
1. `search_navbars`: Fuzzy search over 100+ production navbar component designs by style, theme, and framework.
2. `get_navbar`: Returns the complete JSX/Tailwind code for a specified navbar ID.
3. `list_types`: Enumerates available categories (minimalist, floating, mega-menu, glassmorphism, responsive-drawer).
